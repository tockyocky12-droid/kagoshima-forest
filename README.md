# かごしま森林ナビ 大隅

鹿児島県内の複数の市町村の森林を、1つの地図で確認・管理するスマホ向けWebアプリです。
個人（錦江町役場 林務担当）が作成した非公式のアプリです。県・市町村の公式のものではありません。地番・森林簿の内容は参考で、境界や権利を確定するものではありません。

URL：https://tockyocky12-droid.github.io/kagoshima-forest/

## 入っている市町村
大隅地域の9市町（錦江町・南大隅町・肝付町・鹿屋市・垂水市・曽於市・志布志市・大崎町・東串良町）

## できること
- 地番の境界（民有林）と国有林の小班を地図と航空写真に重ねて表示。市町村をまたいで続けて見られます
- 市町村を選んで移動、地番の検索（選んだ市町村の中）
- 森林簿（各自が県のサイトからCSVを読み込み、端末の中だけで使う）による樹種・林齢・所有形態の色分け
- 地番ごとのメモ表示・メモ内部記録・地積・伐採届・施業履歴、踏査ルート（GPS、地点メモと写真、通った地番、一周の面積、GPX/KML）
- 記録は端末の中に保存。「⇅」で別の端末へ受け渡し。町ごとの版（錦江町森林管理システムなど）の記録ファイルも取り込めます
- 地図を端末に保存して、圏外の山林でも表示

## 森林簿と地番の結び付き（小班の件数の割合、2026年10月時点）
- 9割以上：錦江町・肝付町（内之浦町）・東串良町・鹿屋市（串良町・輝北町）・大崎町・志布志市・曽於市
- 低い所：南大隅町、肝付町（高山町）、垂水市、鹿屋市（旧鹿屋市・吾平町）。山林部に座標付きの地番図が公開されていない大字が多いため（地番図の筆数そのものが少ない、または上高隈町・有武町・高牧町・浜田町のように地番図が無い）
- 字の違いの読み替え：大崎町「仮宿」→「假宿」、志布志市「蓮原」→「有明町蓬原」

## データの出典
- 背景地図：国土地理院 地理院タイル（標準地図・写真）
- 地番：法務省 登記所備付地図データ（G空間情報センター／AIGID が変換したもの、CC BY）
- 国有林：国土数値情報（国有林野データ）（国土交通省）を加工して作成
- 森林簿：この成果品は、鹿児島県森林資源情報データ（ダウンロード）から作成したものである（森林簿のデータはこのリポジトリには置いていません）

## 仕組み（作る人向け）
- アプリ本体（index.html・sw.js）は、my-first-repo の app/ と同じものです。my-first-repo で `python3 tools/sync_towns.py` を実行すると、こちらにも写ります
- 市町村ごとの違いは config.js（munis）と munis.json だけです
- 市町村の足し方：munis.json と config.js に1件足し、`python3 tools/build_region.py add 市町村コード 地番.geojson`
- 地番データは約2km四方ごとのファイルに分け、画面に映った所だけ読みます（通信量を減らす）。国有林も約5km四方ごとに分けています。地番の検索は市町村ごとの一覧（search.json）で探し、当てはまる所だけ読みます
- 森林簿の大字名に合併前の町名が付かない場合（「上名」と「吾平町上名」など）は、旧町名を付けて地番データの大字名と照らし合わせます
- 容量の目安は1リポジトリ1GB。足りなくなったら、地番データを別のリポジトリに分けます
